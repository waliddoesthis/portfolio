Model card · MC-01 · PyTorchDeep learning

Flow classifier for IDS

CNN-BiLSTM + multi-head attention pooling · ~0.98M parameters
Task
Label every network flow as benign or one of 14 attack families, with severity and confidence.
Data
CSE-CIC-IDS2018: 16.2M flows, 47 features each, about 16 GB of CICFlowMeter CSVs.
Results
Macro-F1 0.7711 over 15 classes, accuracy 91.6%, benign recall 98.6% on 212,330 held-out flows.
Limits
Infiltration overlaps benign traffic in feature space. The three web-attack classes have only a few hundred samples.
What I learnedStacking oversampling, weighted sampling and class weights gave the model a uniform prior and collapsed benign recall to 0.29. Logit adjustment plus focal loss fixed it, and adding the class prior back at inference lifts macro-F1 from 0.64 to 0.77.

  3. Conv1d ×2 + GELUkernel 3, local feature patterns
  4. BiLSTM ×2hidden 128, both directions
  5. Attention pooling4 heads
  6. MLP head13 classes
  7. LR splitterrestores 3 web-attack classes → 15
  8. Alertlabel · severity · confidence → hashed to ledger
Model card · MC-02 · PythonLLM security

EcoRoute router

Weighted decision graph · calibrated P(correct) per model
Task
Send each LLM request to the cheapest model likely to answer it correctly, but only among models cleared for the data's sensitivity level.
Method
A graph links each prompt to skills, a difficulty level and its 32 most similar past prompts. A PII model plus caller labels set the sensitivity level first.
Data
SPROUT prompts and BigCodeBench coding tasks. Tested on 4,295 held-out prompts.
Limits
Predicting which model solves a coding task is the weak spot (AUC 0.65). Research prototype, not run in production.
